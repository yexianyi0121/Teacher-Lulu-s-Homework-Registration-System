## §0 铁律（在 V2 L-1~L-4 上追加）

- **L-5 数据安全优先于一切**：任何可能让老师数据变少的行为（写盘、清理、迁移、切换视图）都必须先有「可恢复」路径。
- **L-6 颜色不许再看「四档」**：等级格子用 §3.2 的七档色表，分数格子用四档色，二者的判定源不同、代码路径必须分开。
- **L-7 判定只准有一个入口**：`isPassed()` / `tierOfPercent()` / `classifyRoster()` 三个纯函数是唯一真理，UI 不得自行判断「是否过关」。
- **L-8 交互必须有 E2E**：凡涉及状态机（汇总切换、补交、过关规则、导入恢复）的改动，PR 必须附一条**UI 驱动**的 E2E，禁止只写单测或只截静态图。
- **L-9 不新增运行时依赖**：沿用 V2 白名单（react / zustand / html-to-image / clsx）。图标生成允许用 devDependency 的 Playwright 做一次性栅格化，产物入库。

### 2.3 不变量增量

- **INV-21**：`percentOfValue` 对 `score` 的 `maxScore` 兜底为 100，**永不返回 `null`**（除 `pass`/`text`）。
- **INV-22**：`makeup != null` 的必要条件是 `status ∈ {missing, leave}`；写入口只允许 `setMakeup()`。
- **INV-23**：`PosterTarget.mode === 'single'` 时 `sheetId` 必须存在且属于当天；否则回退到 `daily`。
- **INV-24**：写盘函数 `saveState()` 必须先过 `shouldBlockOverwrite()`，不得被任何调用方绕过。

## §3 模块设计

### 3.1 `domain/passRule.ts`（新增，唯一过关入口）

```ts
export const DEFAULT_PASS_RULE: PassRule = {
  kind: 'mixed',
  gradePass: ['A+', 'A'],
  dictationAutoPass: true,
};

/** 全系统唯一的「是否过关」判定 */
export function isPassed(e: Entry | undefined, s: ScoringScheme, rule: PassRule): boolean {
  if (!e) return false;
  if (e.status !== 'normal') return false;                 // 缺交/请假 → 不过关
  if (e.pass) return true;                                 // 手打 √
  const p = percentOf(e, s);
  if (p !== null) {
    if (gtePct(p, s.passRate)) return true;                // 百分达标（所有规则都认）
    if (e.value?.kind === 'grade' && rule.kind !== 'percent') {
      return rule.gradePass.includes(e.value.grade);       // 等级白名单
    }
    return false;
  }
  if (e.value?.kind === 'text') {
    const k = classifyDictation(e.value.text);
    return rule.dictationAutoPass && k.kind === 'perfect';
  }
  return false;
}
```

> **为什么「百分达标」对所有规则都认**：老师改成「A/A+ 算过关」时，她的本意是「分数及格也算过关」，不是「只有 A 档算过关」。若严格按等级白名单排除百分，会让 85 分（B+）从「过关」变「未过关」，与「达标率」统计口径打架（IV-19 一致性）。

调用点必须全部换成它：`stats.ts`（`qualifiedRate`）、`roster.ts`、`poster.ts`、`points.ts`、`Grid/Cell`、`FilterToggle`、`MakeupModal` 的候选判断。

### 3.4 `domain/scoreInput.ts`（新增，分数校验唯一入口）

```ts
export type ScoreCheck =
  | { ok: true; value: number }
  | { ok: false; reason: 'NAN' | 'NEGATIVE' | 'TOO_BIG' | 'TOO_MANY_DECIMALS' | 'EMPTY' };

export function checkScore(text: string, max: number, decimals: number): ScoreCheck;
export function sanitizeScoreInput(text: string, max: number, decimals: number): string | null;
```

- `sanitizeScoreInput`：全角→半角（`\uFF10-\uFF19` → `0-9`，`\uFF0E`→`.`），去空白与制表符，只保留 `[0-9.]`；清洗后仍非法返回 `null`（调用方整条拒绝）。
- `appendBuffer` 里所有字符先过 `sanitizeScoreInput` 的单字符版；`-`/`+`/`e` 直接 `return`。
- `commitBuffer` 用 `checkScore` 二次校验，失败 → `setCellError(no)`（红框 1.5s，纯 UI 状态，不入 store 持久化）+ `showToast(reason 文案)`。
- `Cell` 增加 `data-error` 属性 → CSS `.cell[data-error="1"] { box-shadow: 0 0 0 2px #E57373 inset }`。

### 3.6 海报：切换状态机（**修复 `App.tsx:181` 过期闭包**）

**现有 bug 代码**
```tsx
// App.tsx:181（错）
{modal === 'poster' ? <PosterModal onRegenerate={() => handlePoster(posterMode)} /> : null}
```
`PosterModal` 内部 `setMode(next)` 后调用 `onRegenerate()`，而 `onRegenerate` 里的 `posterMode` 是切换前的值 → 又被 `setPosterMode(旧值)` 覆盖 → 画面不变。

**正确实现**
```tsx
// store/uiSlice.ts
posterTarget: PosterTarget = { mode: 'daily' };
setPosterTarget(t) { set({ posterTarget: t }); }

// App.tsx
const posterTarget = useStore((s) => s.posterTarget);
const handlePoster = (target: PosterTarget) => {
  const st = useStore.getState();
  st.setPosterTarget(target);
  if (target.mode === 'daily' && !hasAnyToday(st)) { st.showToast('今日暂无登记', 'warn'); return; }
  if (target.mode === 'week' && !hasAnyThisWeek(st)) { st.showToast('本周暂无登记', 'warn'); return; }
  if (st.posterUrl) URL.revokeObjectURL(st.posterUrl);
  st.setPoster(null, null); st.setPosterLoading(true);
  generatingRef.current = true; setStage(true);
};
…
{modal === 'poster' && (
  <PosterModal
    target={posterTarget}
    onSwitch={handlePoster}                  // 传「目标」，不读闭包
    onRegenerate={() => handlePoster(useStore.getState().posterTarget)}
  />
)}
```

- `PosterModal` 内**禁止**再调 `setPosterMode`；只调用 `onSwitch(next)`。
- 单条模式渲染一个 `<select>`：选项来自 `listSheetsOfDay(records, history, classId, date)`（按 `createdAt` 升序），选中即 `onSwitch({ mode:'single', sheetId })`。
- `PosterRaster` 增加 `target` 依赖：`useEffect(..., [target])`，target 变化 → `onReady(node)` 重新栅格化（由父组件 stage 控制）。
- 旧的 `posterMode` 字段**删除**（迁移时丢弃，不兼容保留）。

const isEmpty = (s) => s.records.length === 0 && s.history.length === 0;

## §4 交互细节（易错点，必须按此实现）

### 4.1 单元格优先级（自上而下短路）

```
请假(status=leave) > 缺交(status=missing) > 过关(pass) > 值(grade/score/text) > 空
```
`badge` 与主值正交：`missing + makeup` 同时成立时，主值仍显示「×」，badge 显示「补」，底色用 `madeup`。

### 4.2 听写「全对」

- `value = {kind:'text', text:'全对'}` → 主值文本 `全对`，`kind='text'`，`tone='green'`，**不再**渲染 `√` 主值。
- 若 `isPassed` 为真 → 右上角出现 **✅ 小角标**（10px，绿底白勾），表示「自动过关」；手工 `G` 过关仍是主值 `√`。

### 4.3 工具栏两行

- 第一行：语音 / 盖章 / 过关 / 只看未过关 / 补交 / 缺交 / 请假 / 全选
- 第二行：报表生成 / 截图发群 / 当日汇总 / 本周汇总 / 积分 / 导出 / 清空 / 更新修改
- 行高统一 `var(--btn-h) + 8px`，两行间距 8px；1366 宽度下不换行（20 个按钮按 compact 尺寸 ≈ 1240px 可容纳）。

### 4.4 只看未过关

- 过滤基于 `isPassed`（含过关规则），排除 `leave`（请假不算未过关）。
- 提示条：`👁 只看未过关：{k} 人 / 共 {N} 人（编号保持原学号）`。
- 过滤不持久化（每次刷新重置）。

## §6 时序

### 6.1 启动

```
main.tsx: bootstrap()
  → loadState()               # v3 优先；失败回落 v2 迁移；再失败回落快照
  → replaceState(state)       # 此刻起 booted=true
  → render(<App/>)
  → useAutoSave 订阅（booted 之前 flush 直接 return）
  → readEnvMark()/writeEnvMark() → envMismatch?
  → 若 blocked/corrupt/无数据但快照有 → 顶部黄条
```

### 6.2 切换汇总

```
点击「切换为当日汇总」
  → onSwitch({mode:'daily'})
  → setPosterTarget / revoke 旧 URL / setPosterLoading(true) / setStage(true)
  → <PosterRaster target> 渲染对应 DOM
  → onReady(node) → rasterizeWithRetry → setPoster(url, blob)
  → 预览替换、按钮恢复可用
```

### 6.3 导入恢复

```
选择文件 → importAll(text) → 校验失败：Toast（reason）并终止
  → 成功：openConfirm('将覆盖当前 N 条记录…') 
  → 确认：snapshotCurrent()（写 xq.preimport.{ts} + 内存 undo）
  → replaceState(imported) → 立即 flush（跳过覆盖保护）
  → Toast「已恢复，可 Ctrl+Z 退回」
```

## §11 风险与回滚

| 风险 | 影响 | 缓解 |
|---|---|---|
| v2→v3 迁移写坏数据 | 老师数据丢失 | 迁移前备份 `xq.backup.v2`；迁移纯函数 + 单测；失败只读不写 |
| 覆盖保护误拦（老师清空后想保存空态） | 无法清空 | 覆盖保护只在「内存空 + 磁盘非空」时触发；提供【我确认清空】按钮（写 `xq.emptyConfirmed.{ts}` 后放行） |
| 颜色改造破坏逐字回归 | 报表/海报断言挂 | 颜色只改 CSS 与 `data-*`，不动文本；R-1~R-9 必须绿 |
| 本周汇总过大崩浏览器 | 白屏 | 分卷阈值 16000px；>8000 时直接分卷 |
| PWA 图标在 file:// 不显示 | 无 | favicon 用相对路径 + SVG；E2E-33 双协议断言 |
| 老师不认同新颜色/表情 | 体验倒退 | 全部可在设置关闭（表情）、可回退（`GRADE_TONE` 单表改色） |

**回滚策略**：`v2.2.0` 若出现数据问题，卸载新版本后用户仍可用 `xq.backup.v2` + 导出的 JSON 恢复到 v2.0.1；**旧版本不得读取 v3 数据**（`version > 2` 时只读并提示——V2 已有此逻辑，保留）。
