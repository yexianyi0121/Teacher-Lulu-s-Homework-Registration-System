## 1. 本轮修了什么

- 修复 提示条在 1366 宽屏下被挤满：左侧已有「按键 = 等级」色块，文字里又列了一遍 `1 A+ 2 A 3 A- …`（FR-77.1）。

## 2. 根因

`buildHint()` 的文字产物与 `HintBar` 的键位色块（v2.5.10 FR-68.1 加的）是同一份信息的两套表达：
- 色块：每个启用等级一个小片，如 `1 A+`、`2 A`……
- 文字：`💡 1 A+ 2 A 3 A- 4 B 5 B- 6 C 7 D · 空格 盖章 · X 缺交 · L 请假`

色块出现后，文字前半段就是纯重复，而且随等级增多越来越长，
在 1366 宽度下与「未启用 B+，点此添加」按钮争位置，提示条看起来又长又挤。

## 3. 改了什么

| 文件 | 改动 |
| --- | --- |
| `src/domain/hint.ts` | `buildHint()` 新增第 5 个可选参数 `keysInChips`（默认 `false`，纯文字场景保持原样）；为 `true` 时键位描述由 `1 A+ 2 A …` 收敛为「数字＝等级」 |
| `src/components/HintBar.tsx` | 先算键位色块 `pairs`，有色块时传 `keysInChips = true`；提示文字变为 `💡 数字＝等级 · 空格 盖章 · X 缺交 · L 请假` |
| `tests/unit/hint.test.ts` | 新增 3 例：色块场景不再含 `1 A+`、混合表同样收敛、无色块时仍逐档列出 |
| `tests/e2e/v4-digit.spec.ts` | 键位断言从「文字含 `1 A+`」改为「色块有 8 个且首个含 A+」；切到分数语义后断言色块为 0 |

- **色块本身不动**：它是「按键 = 等级」的唯一权威展示，也是点进本表设置的入口提示。
- **纯文字场景保留原样**：`buildHint()` 默认仍逐档列出，供报表/测试等无色块的调用方使用。
