# 需求说明书 v2.5.5 —— 数据落盘安全（FR-58）

> 变更基线：v2.5.4（`f2fe6d4`）
> 来源：v2.5.3 上线后的数据安全专项审查（D-01~D-15）。

---

## 0. 背景：为什么「写盘失败」比「崩溃」更危险

「崩溃」老师立刻就知道出事了，会重来。
「写盘失败」老师**完全不知道**：格子显示 A+😄✓、Toast 说已保存、统计条在动 ——
她关了浏览器，第二天打开，一整天的录入全没了，而且**事后没有任何线索**。

审查实测（D-01）：把 `localStorage` 配额打满后继续录 2/3/4 号，
四格全部显示录入成功、无 toast，磁盘上只有 1 号，重开后 `["1A🙂✓","2","3","4"]`。
唯一的提示是一条**可以点「知道了」关掉、并且关掉后永不重现**的横幅。

> 结论：写盘失败必须做到三件事 —— **能被看见、能说清原因、不提供「假装没事」的出口**。

---

## FR-58.1 写盘失败必须区分原因

`SaveResult` 增加 `reason: 'quota' | 'unavailable'`：

- `QuotaExceededError` / `NS_ERROR_DOM_QUOTA_REACHED` / `code === 22` → `'quota'`（空间满）
- 其它异常 → `'unavailable'`（存储被禁用）

两种原因给的自救办法完全不同，不能合并成一句「存储不可用」：

| 原因 | 老师能做什么 |
| --- | --- |
| `quota` | 立刻导出备份 → 到「设置 → 历史记录」删旧的 → 刷新页面 |
| `unavailable` | 导出备份 → 换用 Chrome / Edge 打开 |

## FR-58.2 失败横幅不可消除、必须引导自救

`storageDegraded` 横幅改为：

1. **红色**（`#FDECEC` 底 / `#B23B3B` 字），与普通提示区分；
2. 文案写明「刚才做的修改**没有存上**，关掉页面就会丢」；
3. 按 `storageErrorReason` 给不同自救建议（见上表）；
4. **不提供「知道了」按钮** —— 只提供「📦 去导出备份」。横幅只在真正写盘成功时自动消失。

移除 `App.tsx` 里 `setStorageDegraded(false)` 的手动关闭入口。

## FR-58.3 隔离副本与导入快照必须修剪

`xq.corrupt.*` / `xq.blocked.*` / `xq.preimport.*` 原本**只增不减**（D-14），
长期使用会吃满配额，反过来诱发 FR-58.1 的 `quota`。这是典型的「缺陷喂自己」。

**规则**：每种前缀最多保留最近 **2** 条，写入新的一条后立即按时间排序修剪。

新增 `infra/storage.ts: savePreimportSnapshot(json): boolean`，写入 + 修剪一步完成，
供花名册导入（FR-57.3）与导入恢复共用。

## FR-58.4 只读态不得导出空备份

**缺陷 D-04**：数据读坏进入只读态时，面板第一个按钮「导出当前数据」导出的是**内存里的空状态**
（5.7KB / `records = 0`）。老师以为得救了，实际交出的是一份空文件；
而面板又让她「清空并重来」却被覆盖保护拦住 —— 按提示操作会进退两难。

**规则**：只读态的主按钮改为「**导出原始数据**」：

1. 先 `readRawStateText()` 取磁盘原文，有则导出 `学情原始数据-<日期>.json`，
   Toast 说「已导出磁盘上的原始数据（不是空的）」；
2. 磁盘也读不到时才回退到导内存状态，并明确 Toast 告知「导出的是内存里的内容」。

## FR-58.5 备份文件名必须精确到秒

**缺陷 D-07**：`stampForFile()` 只到分钟，老师一分钟内连导两次会得到同名文件，
下载目录里后一份顶掉前一份 —— **备份把备份弄丢了**。
改为 `YYYYMMDD-HHmmss`。

## FR-58.6 清空历史记录必须打字确认

**缺陷 D-11**：历史记录是「本周汇总 / 成长曲线 / 月度·学期导出」的唯一数据源，
但「清空历史记录」只要点确定就永久删光，比「清空全部数据」（要求打字「清空」）还宽松。

**规则**：`requireText: '清空'`，并在确认框里写明：

- 当前正在录的这一条不受影响；
- 本周汇总 / 成长曲线 / 月度·学期导出会随之变空；
- 不可撤销；
- 建议先导出备份。

## 验收标准

| 编号 | 场景 | 期望 |
| --- | --- | --- |
| A-123 | 让 `xq.state.v4` 的 setItem 抛 `QuotaExceededError`，再录 2 号 | 出现红色横幅，文案含「空间满了」与「没有存上」；**没有「知道了」按钮** |

| A-130 | 清空历史记录 | 必须输入「清空」才能确认 |
