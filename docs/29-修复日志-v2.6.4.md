# 29 · 修复日志 · v2.6.4

> 版本：2.6.4
> 性质：用户反馈修复 + 界面小改进（本轮为 bug 修复日志，不进入需求文档）
> 验收：A-160 ~ A-168

## 1. 本轮修了什么

- 新增 按登记表导出表格：系统设置里可以按日期勾选若干张表，导出为便于打印 / 存档的 CSV（FR-74.1）。
- 修复 取消「允许 ✓ 过关标记」后，已打的手工过关标记既不提示清空、也不刷新显示（FR-74.2）。
- 修复 「听写全对自动算过关」出现在所有登记类型的本表设置里，且名称不准确（FR-74.3）。
- 优化 主界面常驻显示本表方案与过关规则，点一下进本表设置（FR-75.1）。
- 优化 顶栏系统名换字体、放大、去掉花，时间与学期贴到标题右边（FR-75.2）。
- 优化 学科列表改为初中学段（FR-75.3）。
- 优化 作业内容输入框收窄、新建登记按钮改实底主色，突出「先建一张表」（FR-75.4）。
- 优化 系统设置里删掉「过关规则」历史提醒（FR-75.5）。

## 2. 根因

### 2.1 手工过关标记不在「值」里（FR-74.2）

键 `G`（手打过关）写入的是 `Entry.pass = true`，同时把 `value` 顶成 `null`。而 v2.6.3 的清空逻辑
`pruneEntries` 里第一句就是「没有值就当空格子跳过」，于是这种「只有标记、没有值」的格子永远走不到判断，
自然既不计数、也不提示、更不会刷新。

### 2.2 听写开关没有跟着登记类型（FR-74.3）

「听写全对自动算过关」写死在过关规则区里，只在语义上属于听写 / 默写表；其他模板照样显示，老师会以为它有用。

### 2.3 其他三条是体验缺口

方案类型与过关规则搬到「本表设置」后，主界面反而看不到当前口径；学科列表还是小学口径；
参数行里「作业内容」输入框过宽，把「新建登记」挤成不起眼的次要按钮。

## 5. 明确不改

- 过关判定入口仍只有 `isPassed(entry, scheme)` 一处（v2.6.3 口径不变）。
- 导出仍走 CSV（UTF-8 BOM，Excel 双击不乱码），不引入 xlsx 依赖。
- 「改名 = 新建 + 删旧」的既有规则不变，本轮只做导出与清空判定。
