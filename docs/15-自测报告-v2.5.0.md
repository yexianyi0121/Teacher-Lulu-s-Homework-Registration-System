## 3. 过程中发现并修复的缺陷

| # | 缺陷 | 根因 | 修复 |
|---|------|------|------|
| 1 | 重定向页方案引发 E2E 无限循环 | SW `navigateFallback` 用缓存的重定向页响应中文入口 → meta refresh → 再被 SW 拦截 | **ADR-30：弃用重定向页，改完整镜像**（fallback 也不再需要 denylist） |
| 2 | `goto('/')` 后 evaluate 必炸 | 0 秒 meta refresh 摧毁执行上下文 | 同上，镜像方案根治；fixture 无需等待 |
| 3 | Edge `--app` 打不开中文 file:// URL | 未编码中文被 Edge `--app` **静默拒绝**（https 对照实验定位） | 启动器借 PowerShell `[uri]::EscapeUriString` 编码（保留 `/`、`:`，只编码中文；`EscapeDataString` 会把路径结构也编码，实测排除） |
| 4 | postbuild 首版非幂等 | 重复运行把重定向页/镜像又 rename 成中文入口，覆盖真应用 | 改名逻辑改为"APP 不存在才 rename"，镜像一律重建（vite `emptyOutDir` 兜底） |
