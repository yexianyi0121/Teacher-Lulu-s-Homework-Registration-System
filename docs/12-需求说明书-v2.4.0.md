## 2. 设计决策（ADR 顺延）

1. **常量放 domain 层**（`src/domain/appInfo.ts`）：与 `theme.ts` 同款纯常量模块，可脱离 DOM 单测；版本号镜像 + 同步测试，避免两处漂移。
2. **链接色单独立令牌 `--link: #2F6FBA`**（不随主题换）：night 主题的 `--brand`（#8E7CD8）压白底只有 ≈3.5:1，不够 4.5:1；固定蓝六套通用，实测 ≈5.1:1（E2E-42b 实算兜底）。
3. **不新增任何网络请求**：GitHub / mailto 都是用户主动点击的原生跳转，页面自身零请求的承诺不破（FR-52.7 同款思路：测试只验证 href，不真正发起）。
4. **不改数据模型**：`PersistedStateV4` 原样，无迁移；关于分区是纯展示。
