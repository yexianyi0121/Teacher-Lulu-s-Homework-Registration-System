## 1. 本轮修了什么

- 修复 当日 / 本周汇总图底部会多出一行与某张表相同的评价语（FR-76.5）。

## 2. 根因

汇总图的模型里还留着一个「整图评价语」字段（`SummaryModel.comment` / `WeekModel.comment`），
它的来源是**当前草稿那张表**的评价语。v2.5.10 把评价语改成「每张表各写各的」之后，
这个字段就成了纯冗余：草稿那张表的评价语已经印在它自己的 section 里，
页脚又把同一条再印一遍，看起来就像「最后一张表的评价语出错了」。

复现路径：建 3 张登记表 → 在当日汇总里依次给三张表写评价语 → 点「重新生成」，
底部会多出一行，内容与第一张表（当时的草稿）相同。

## 3. 改了什么

| 文件 | 改动 |
| --- | --- |
| `src/store/selectors.ts` | `selectSummary()` / `selectWeek()` 不再把 `draft.comment ?? settings.defaultComment` 传给汇总模型，汇总图因此没有整图评价语（FR-76.5） |
| `tests/unit/fr76-summary-comment-unique.test.ts` | 新增 4 个回归：整图 comment 恒为空、每张表评价语各就各位、每条评价语只出现一次、周汇总同理 |
| `tests/e2e/v5-feedback.spec.ts` | 新增 FR-76.5 用例：三张表各写评价语 → 重新生成 → 每条在图上只出现一次 |

单张海报不受影响：它本来就只对应一张表，评价语仍取「这张表的 comment，空则用默认评价语」。

## 4. 验收

## 5. 明确不改

- **不做「整图寄语」**：评价语属于每张表，汇总图只按 section 展示；需要给整张图写字时用单张海报。
- **默认评价语仍保留**：设置里的默认评价语只在单张海报里作为兜底，不再往汇总图页脚塞。
