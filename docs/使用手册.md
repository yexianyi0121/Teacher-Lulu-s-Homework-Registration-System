# 学情登记管理系统 · 使用手册

版本：v2.8.3

本系统用于**课堂作业、听写默写、质量监测**等场景的极速登记：录完即可出报表文案、单条海报与当日/本周汇总长图。
纯前端、纯本地运行——数据只保存在你当前这台电脑的浏览器里，不上传服务器，断网也能用。

---

## 一、打开系统

解压后进入 `dist` 文件夹，任选一种：

| 入口 | 说明 |
| --- | --- |
| `启动学情登记系统.cmd`（推荐） | 无边框窗口，像桌面应用一样打开（Windows + Edge/Chrome） |
| `学情登记系统.html` | 用浏览器直接打开 |
| `index.html` | 与上面内容完全相同，兼容旧入口 |

首次双击 `.cmd` 若出现「安全警告」，点「打开」即可，只需一次。

> 数据保存在**这台电脑的这个浏览器**里。换电脑、换浏览器或清理浏览器数据前，请先导出备份。

---

## 二、第一次使用

1. 点右上角 **⚙️ 设置**：填写班级、学校、老师姓名，确认学生人数。
2. 名单不是 1～N 号？点顶栏 **📁** 导入花名册（支持粘贴文本、CSV、TXT、Excel）。
3. 选择「登记类型」→ 点 **＋ 新建登记**，在弹出的窗口里输入作业内容 → 确定，开始录入。

---

## 三、界面速览

- **顶栏**：系统名、当前时间与学期、班级切换、秒跳开关、搜学号、导入花名册、设置。
- **参数行**：登记类型 / 日期 / 作业内容（只读展示当前表名）/ ＋ 新建登记 / ✏️ 修改表名 / 选择登记表 / 删除此表。
- **输出栏**：报表生成、单条海报、当日汇总、本周汇总。
- **录入栏**：语音、盖章、过关、补交、缺交、请假、全选、只看未过关、本表设置、清空、**💾 更新修改**。
- **提示条**：当前等级按键说明与快捷键。
- **网格**：每个格子是一名学生，格子下方可显示姓名。

---

## 四、五种登记类型

| 类型 | 适用场景 | 录入方式 |
| --- | --- | --- |
| 常规作业 | 日常作业等级 | 1=A+、2=A、3=A-、4=B+、5=B、6=B-、7=C、8=D（可在本表设置里调整） |
| 听写默写 | 听写、默写 | 数字 = 错几（0 或「全对」= 全对）；也可打勾过关 |
| 质量监测 | 单元测验、考试 | 直接输入分数（如 87.5），回车确认 |
| 混合制 | 同一张表既有等级又有分数 | 数字默认按等级；本表设置可改为「数字＝分数」 |
| 自定义 | 其他 | 自由配置 |

> 每张表都可以在 **⚙️ 本表设置** 里单独调整评分方案、满分、过关规则，互不影响。

---

## 五、录入操作

- **单击格子**选中；**双击格子**可手动输入文字。
- 数字键录等级或分数；输入过程中按 **Enter** 立即确认。
- **G** = 过关；**X** = 缺交；**L** = 请假；**空格** = 盖章（已更正/优秀）。
- **Ctrl+Z / Ctrl+Y** 撤销与重做。
- **Ctrl+S** 或点 **💾 更新修改**：把当前表保存进「历史记录」。
- 多选：按住 Shift 点两个格子可选中区间；点「全选」选中所有有内容的格子，再批量操作。

> 录完一班后，请顺手点一次 **💾 更新修改**。系统在你切换日期 / 类型 / 登记表 / 班级前也会提醒你。

### 新建登记与修改表名

- 作业内容框**不能直接输入**：点「＋ 新建登记」→ 在弹窗里填写名称 →「创建登记表」。
- 每天 / 每种登记类型第一次使用时，页面不显示学生格子，只显示一个大大的「＋ 新建登记」按钮——先建表，再登记。
- 表建好后，点「✏️ 修改表名」可以原地改名，**已录入的数据不会丢**；同一天同一类型下不允许重名。
- 切到历史日期且该类型当天没有表时，同样会显示新建按钮，不会凭空显示一张空表。

---

## 六、搜学号

顶栏「搜学号」输入数字：命中的学生会以**金色描边高亮**，其余格子变暗，方便快速定位。
按 **Enter** 直接跳到命中学生，按 **Tab** 在多个命中之间切换。

---

## 七、日期与历史

- 日期框点开是月历；**有登记记录的日期下方有小圆点**，鼠标悬浮圆点日期会显示当天已登记的表名。
- 月历支持翻月与「回到今天」，翻月不会改变当前登记日期。
- 每天打开系统会自动落在**今天**的空表上；昨天的登记仍保存在历史记录中。
- 一张表录入后会自动保存到浏览器；点 **💾 更新修改** 会额外固化进「历史记录」，供汇总与统计使用。

---

## 八、输出：报表、海报、汇总

- **📄 报表生成**：一键生成可发家长群的文字反馈（光荣榜、需更正、未提交等）。
- **🖼 单条海报**：当前这张表的图片海报。
- **🗓 当日汇总**：当天所有登记表的长图。
- **📅 本周汇总**：本周按天拼接的长图，可自动分页。

---

## 九、积分（可选）

在「⋯ 更多 → 积分」里可查看积分榜、手动加减分、设置自动规则（如连续三次全对加 5 分、优秀加 3 分等）。
自动规则只对**新录入**生效，不会追溯修改历史账本。

---

## 十、数据备份与恢复

- **导出全部数据**：设置 → 数据 →「📦 导出全部数据」，得到一个 JSON 备份文件，建议定期导出。
- **导入恢复**：设置 → 数据 →「📥 导入恢复」，选择备份文件。导入为**合并**方式，不会覆盖你现有的登记。
- **备份提醒**：设置里可设「每 7 天 / 30 天提醒一次」或关闭。提醒只弹提示，不会自动下载。

---

## 十一、更新到新版本

设置 → 关于 → **⬆️ 一键更新（下载最新版）**，会打开 GitHub 的 Releases 页面。
下载后替换旧文件即可；**更新不会动浏览器里的数据**，但建议升级前先导出一份备份。

## 十二、常见问题

**Q：换电脑后数据不见了？**
数据存在原电脑的浏览器里。请在原电脑「导出全部数据」，再到新电脑「导入恢复」。

**Q：历史记录里看不到刚录的表？**
请点一次 **💾 更新修改**（或 Ctrl+S）。

**Q：网页提示「浏览器存储空间满了」？**
请立刻导出备份，然后在设置 → 历史记录里清理旧记录，再刷新页面。

**Q：能不能多人同时用？**
建议一个班一台电脑使用；多窗口同时编辑可能互相覆盖，系统会提示并停止保存。

## 十三、数据不见了怎么办（重要）

本系统的数据保存在**这台电脑、这个浏览器配置**里。换浏览器（Edge/Chrome）、换 Edge 配置、用无痕窗口、清理浏览器数据，都会看到“空的系统”，但数据通常还在原来的地方。

### 1. 先排查：数据到底在哪个浏览器配置

双击 `dist` 里的 **`恢复与排查.cmd`**：

- 选 **[1]**：扫描本机所有 Edge / Chrome 配置，列出哪些配置里有学情数据；
- 选 **[3]**：直接选择对应配置打开系统（数据就会回来）。

> 常见原因：Edge 里有多个配置（个人/工作），启动时进了另一个配置。系统现在会自动优先打开“有数据”的那个配置。

### 2. 从自动备份恢复

系统**每次启动前**都会把这个配置里的数据备份到 `%LOCALAPPDATA%\XueQingBackup\`，保留最近 20 次。恢复步骤：

1. 关闭所有 Edge 窗口（包括本系统）；
2. 双击 **`恢复与排查.cmd`**，选 **[2]**；
3. 选择最近的备份编号，恢复完成后重新双击 `启动学情登记系统.cmd`。

### 3. 仍然找不到

- 检查是否换了 Windows 用户、换了电脑、或在另一台设备上登记；
- 如果之前导出过备份 JSON，用【设置 → 导入恢复】导入；
- 不要清理浏览器“Cookie 和网站数据”，那会真的删除数据。

## 十四、Mac + Safari 用户特别说明

Safari 和 Windows 上的 Edge 不是一套存储机制，Mac 用户请特别注意：

1. **Safari 会自动清理“7 天没访问”的网站数据**（智能防跟踪 ITP）。本地 html 也可能被清。请养成**每周【设置 → 导出全部数据】**的习惯。
2. **不要点 Safari 的「清除历史记录 / 管理网站数据」**，那会真正删除本地数据。
3. **不要把程序频繁换文件夹**：Safari 对本地文件（file://）的存储可能按路径隔离，换了目录可能看到“空系统”。
4. 打开后看不到数据？双击 **`学情数据恢复.command`**：
   - [1] 扫描本机含学情数据的文件；
   - [2] 立即备份；
   - [3] 从备份恢复（会先退出 Safari）；
   - [4] 用 Safari 打开系统。
   首次运行若被系统拦截：右键 →「打开」；或在「终端」执行 `chmod +x 学情数据恢复.command` 后再双击。
5. 如果脚本扫描不到任何数据：用 **Time Machine** 恢复 `~/Library/Safari/LocalStorage` 与 `~/Library/Safari/Databases`（恢复前先 ⌘Q 退出 Safari）。
6. 想更稳：Mac 上建议用 **Chrome** 打开同一个 html，并定期导出备份。
