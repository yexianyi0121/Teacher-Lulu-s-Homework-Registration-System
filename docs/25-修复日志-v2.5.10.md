# 25 · 修复日志 · v2.5.10

> 版本：2.5.10
> 性质：用户反馈修复（本轮为 bug 修复日志，不进入需求文档）
> 验收：A-148 ~ A-152

## 1. 本轮修了什么

- 修复 主屏在多张同类型登记表之间无法切换：主界面新增「选择登记表」，只在该模板当天确有多张表时出现，切过去原有数据原样在。
- 修复 汇总图的评价语只能整张写一条：汇总按表分节展示，每张表各自写各自的一条（上限沿用 60 字），空串表示这张表不写。
- 修复 等级旁表情与等级文字互相遮挡、汇总格不显示表情：表情改为在主值下方独立一行，并按主网格 / 海报 / 汇总三种尺寸分别给字号；汇总格不再隐藏表情。
- 修复 提示条看不出启用等级的键位与顺序：提示条把当前方案启用的等级做成带键号的色块，配色与该等级格子一致；「本表设置」里同步显示键位绑定顺序。
- 修复 界面不随屏幕适配：解除 1440px 内容上限，按 1600 / 1920 / 2560 三档逐级放大格子、字号、按钮与图标。

## 2. 关键设计

### FR-66.1 主屏「选择登记表」

- 数据来源仍是 `selectSheetsOfDay`（按完整 key 去重，v2.5.9 FR-64.1），只过滤当前模板。
- 选中项 = 当前草稿的 key；切换走 `switchRecord({ content, sheetId, templateId })`——content + sheetId 正好拼回同一条记录的 key，因此是「回到那张表」，不是新建。
- 只有一张表时不渲染选择器，避免给单表老师添乱。

### FR-66.2 汇总按表写评价语

- `SummarySection.comment` 由该表自己的 `RecordDoc.comment` 提供（空串表示不写）；汇总图仍保留整图页脚语，两者可并存。
- 每日汇总与本周汇总共用同一套按节编辑入口；单条海报模式仍只编辑当前表。
- 写入口集中在海报预览弹窗内：折叠态显示已有评价语，点「写评价语 / 改评价语」展开输入框。

### FR-67.1 表情与主值的版位

- 表情不再 inline 跟在主值后面，而是 `.cell-value` 变成纵向 flex，表情单独一行；`.cell` 的 `overflow:hidden` 因此由「裁掉溢出」变成「正常收在格内」。
- 三种尺寸分别给字号：主网格 .8em、海报 14px、汇总 12px。
- 汇总格（mini）原来 `display:none` 直接不显示表情，现已删除该规则；汇总格高度 52px → 58px 容纳两行。
- 顺手删掉 `.cell[data-mode="homework|quiz"] .cell-value` 两条死规则——`data-mode` 全仓库没有任何地方渲染。

### FR-68.1 提示条等级色块

- `keyMapPairs(buildGradeKeyMap(scheme))` 输出「键号 + 等级」对，键号在前、等级在后，按启用顺序。
- 每个色块的背景 / 边框 / 文字色与该等级格子完全一致（A+ 绿、A- 绿、B/B- 琥珀、C/D 珊瑚/灰）。
- 提示条从固定高度 + 省略号改为可换行，长等级链不再被裁掉。

### FR-69.1 屏幕适配

- `.app-inner` 从 `max-width:1440px` 改为跟随视口（上限 1920px，2560 以上再放到 2200px）。
- 令牌分档：<1280 紧凑（cell 68px）→ 1366 标准（76px）→ ≥1600（88px）→ ≥1920（104px）→ ≥2560（124px）。
- 仍由网格列数断点（10/8/6/5 列）保证窄屏不出现横向滚动，E2E-38 不变。
