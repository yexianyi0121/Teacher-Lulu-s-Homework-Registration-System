# 需求说明书 v2.5.0 —— 入口 App 化（FR-53）

> 版本：v2.5.0 ｜ 日期：2026-10-25 ｜ 来源：用户口头需求（原话）：
> "你的最后一个任务,把index.html换个名称以及一个图标,使得它看上去更像一个app,而不是一个网页"

## 1. 背景与动机

本系统的交付形态是「下载 GitHub ZIP → 解压 → 双击打开」，全程零安装、零部署。但此前入口叫
`dist/index.html`：

- 文件名暴露了"网页源码包"属性，老师看到 `index.html` 容易以为要懂技术；
- 双击后是带地址栏、标签页、书签栏的普通浏览器窗口，观感与"软件/App"差距大；
- 移动端 PWA 安装后的 `start_url` 也指向这个"源码名"入口。

用户要求：换名字 + 配图标 + 整体像 App。

## 2. 需求条目

### FR-53 入口 App 化

**FR-53.1 主入口改名**：构建产物 `dist/index.html` 改名为 **`dist/学情登记系统.html`**，
页面 `<title>` 保持「刘露老师的学情登记本」。验收：解压 ZIP 后看到的是中文名应用文件，
而非 `index.html`。

**FR-53.2 图标**：沿用既有樱花 favicon（`favicon.svg` + `icon-192.png`）——它本就是
App 式圆角图标，v2.3.0 起已随 PWA 三件套交付；本次保证改名后的入口仍正确引用，且
`file://` 直开时浏览器标签/窗口使用该图标。验收：E2E-43b 断言入口 `<head>` 含
favicon/apple-touch-icon/manifest 三链。

**FR-53.3 Windows 无边框启动器**：build 末尾生成 **`dist/启动学情登记系统.cmd`**，
双击后以 Edge/Chrome `--app` 模式打开主入口——无地址栏、无标签页、任务栏图标用页面
favicon，视觉上与桌面应用一致。三重回退：Edge `--app` → Chrome `--app` → 系统默认浏览器。
验收：启动器内容全 ASCII（cmd 按本机代码页解析，非 ASCII 会乱码）；URL 经
`EscapeUriString` 百分号编码（**实测未编码中文 file:// URL 会被 Edge `--app` 静默拒绝**，
2026-10-25 Edge 124 复现）；CRLF 行尾；首运行 SmartScreen 提示语写入注释。

**FR-53.4 兼容镜像**：`dist/index.html` 保留为**完整应用镜像**（与中文入口逐字节相同），
不再是重定向页。理由（ADR-30）：先做过 0 秒 meta-refresh 重定向页，实测三处破坏——
① `Service Worker navigateFallback` 用缓存的重定向页响应中文入口 → 无限循环；②
`goto('/')` 后 0 秒跳转摧毁执行上下文，测试 fixture 全炸；③ 未来任何写 `goto('/')`
的消费者都会踩雷。镜像方案让所有现存/未来入口（`/`、`index.html`、旧书签、PWA fallback）
无感兼容。

**FR-53.5 PWA 直达**：`manifest.webmanifest` 的 `start_url` 改为 `./学情登记系统.html`，
手机「添加到主屏幕」后启动直达。

**FR-53.6 构建链**：`pnpm build` = `vite build && node scripts/inline-dist.mjs &&
node scripts/postbuild-app.mjs`，后处理幂等（重复运行不破坏产物）。

## 3. 明确不做

- 不引入 Electron/Tauri 等真壳：体积、签名、更新链路都违背"下载即用"底线。
- 不改移动端行为：iOS/Android 仍走「添加到主屏幕」获得全屏（既有 FR-49 能力）。
- 不做图标重绘：现有樱花图标已满足"App 观感"，重绘另立需求。
