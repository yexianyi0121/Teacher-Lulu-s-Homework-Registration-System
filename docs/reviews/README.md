## 一句话总结

审查挖出的问题不是"功能没做"，而是**功能做对了，但老师会误以为它做对了**：

- 「我按了全选再点一个，怎么还是只改了一个？」——选区没退出，高亮还亮着
- 「我点了缺交，后来补录了个 A+，怎么缺交记录没了？」——状态被静默改写
- 「我撤了一步，接着录下一个，怎么记到别人身上了？」——撤销把焦点搬到了邻居格
- 「存储写满了，界面一切正常」——刷新才发现全没了
- 「我改了分数制，光荣榜怎么没变？」——存量等级值还在按字母秩参与判定
