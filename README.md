# 学情登记分析系统

> 为初中语文老师刘露定制的**作业 / 测验极速登记**工具：一节早读就能录完全班，一键生成可发群的报表文案与学情海报。
>
> 纯前端、纯本地、**零网络请求**（唯一例外：老师自己点「语音」按钮时才用浏览器语音识别）。断网、飞行模式、关掉 Wi-Fi 都能照常用。

---

## 1. 怎么用（老师视角）

### 方式 A：双击打开（最省事）

直接双击仓库里的 **`dist/index.html`**，用 Chrome / Edge 打开即可，无需装任何东西、无需联网、无需服务器。

> 首次打开后建议按 `Ctrl+D` 收藏，或把 `dist` 文件夹拷到桌面 / 优盘随身带。
> 数据保存在**这台电脑的这个浏览器**里，换电脑请用【设置 → 导出备份】搬数据。

### 方式 B：同学 / 同事访问（可选，需要自己有个静态托管）

`dist/` 是完整的静态站点，直接扔到任意静态托管（GitHub Pages、内网 nginx）即可；因为是 PWA，装到桌面后离线也能用。

### 换一台电脑用（教室讲台 / 办公室）

**① U 盘拷 `dist` 文件夹（最简单，全程离线）**

1. 把 `dist` 整个文件夹拷到讲台电脑，例如 `D:\学情登记\`。
2. 双击里面的 `index.html`（用 Edge / Chrome 打开）。
3. 想让它看起来像个软件？右键 `index.html` → 发送到 → 桌面快捷方式，再右键快捷方式 → 属性，把「目标」改成：

   ```
   "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --app="file:///D:/学情登记/index.html"
   ```

   双击就是**无地址栏的独立窗口**（已实测可用，50 格正常渲染）。

**② 校内网静态托管（多台电脑同一个网址）**

把 `dist` 放到校内 web 目录，各台电脑访问 `http://校内地址/学情登记/` 即可；这种走 http 的方式还能「安装到桌面」（PWA，断网也能开）。注意这只是**同一份程序**，数据仍是各机器各自一份。

**③ 只在讲台临时用一次**：拷 `dist` → 打开 → 录完导出备份 JSON 带走。

### ⚠️ 数据不跟着程序走（必读）

- 数据存在**「这台电脑 + 这个浏览器」**的 localStorage 里。程序换目录、改文件夹名都不影响（实测：同一台机器上把 `dist` 改名或换路径，数据仍在，因为 `file://` 共用一份存储）。
- **换电脑 = 空白**。搬家方式：【设置 → 📦 导出备份】得到 JSON → 新电脑【设置 → 📥 导入备份】（导入会覆盖目标机全部数据，有二次确认）。
- **换浏览器**（Edge → Chrome）也算换环境，同样要导出 / 导入一次。
- 讲台电脑若装了**还原卡 / 公共机房策略**，关机还原会把浏览器数据抹掉：当天录完就用【截图发群】发出去 + 【导出备份】存 U 盘，长期数据留在办公电脑。

### 第一次打开要做的三件事

1. 【设置】⚙️ 里填班级名、学校名、老师姓名（海报署名用），确认学生人数（默认 50）。
2. 名单不是 1~50 号？点 📁 导入花名册：粘贴「1 张三」这种一行一号的文本，或导入 CSV / TXT。
3. 录入时先选模式（常规作业 / 单元测试 / 听写默写）、填日期和作业内容，然后开始敲键盘。

---

## 2. 三种模式

| 模式 | 每格记什么 | 怎么录 |
|---|---|---|
| 常规作业 | 等级 `A+ / A / A- / √ / ×` | 键盘 `1 2 3 4 5`；`1`=`A+`、`2`=`A`、`3`=`A-`、`4`=`×`、`5`=`√` |
| 单元测试 | 分数 0~100（可带一位小数） | 直接敲数字，`87.5` 敲完按 `Enter` 才跳下一格；顶部实时出统计条与图表 |
| 听写默写 | 自由文本，如 `错2` / `全对` / `缺` | 选中格子直接打字，`Enter` 或点别处提交 |

- **秒跳**（右上角 ⚡）：开着时一次按键自动跳下一格，50 个人盲打不用看屏幕；关掉时按 `Enter` 才动。
- **空格盖章**：选中格子按空格，在「无 → 已更正 → 待更正 → 无」之间循环，用于标记改错情况。
- **人数少了不丢数据**：把人数从 50 调到 40，41~50 号只是隐藏；调回 50 号原值全在。

## 3. 快捷键

| 键 | 作用 |
|---|---|
| `1`~`5` | 常规作业：`A+ A A- × √` |
| `0`~`9` `.` | 单元测试：分数输入（`Enter` 提交并前进） |
| `Tab` / `Shift+Tab` | 下一格 / 上一格 |
| 方向键 | 上下左右移动（按当前列数） |
| `空格` | 盖章 |
| `Delete` / `Backspace` | 清空当前格 |
| `/` | 搜索学号，输入数字后 `Enter` 直接跳过去 |
| `Ctrl+Z` / `Ctrl+Shift+Z` | 撤销 / 重做（含整批操作） |
| `Ctrl+S` | 把当前记录存入历史（「更新修改」） |
| `Ctrl+M` | 开关语音录入 |
| `Esc` | 关弹窗 / 取消编辑 |

## 4. 出文案、出海报

- **报表生成**：一键生成可直接粘到微信群的通知文案（光荣榜 / 暂未提交 / 需更正 / 已更正），可复制或下载 `.txt`。名单按 70 半角宽自动折行，粘到微信不会挤成一团。
- **截图发群**：离屏渲染一张 1080px 宽的学情海报，可直接「复制图片」再粘到微信，或下载 PNG。
- **数据分析**：仅单元测试模式出现，含分数段环形图、新老对比柱状图、最近 8 次趋势折线图；可下拉选历史记录做对比。

## 5. 数据与隐私

- 全部数据存在浏览器 `localStorage`，并每 30 秒在 IndexedDB 留一份快照（保留 5 份），刷新 / 强关不丢。
- 页面不发任何网络请求；语音识别只在**你主动点击语音按钮**后才调用浏览器自带的 Web Speech API（该能力由浏览器实现，可能联网）。
- 【设置】里可导出 / 导入 JSON 备份；【清空】只清当前这一条记录，误清可用 `Ctrl+Z` 整体恢复。

### 数据能存多久（一周 / 一个月 / 一学期）

存了三层，各层的保留规则不同：

| 层 | 存什么 | 保留规则 | 怎么触发 |
|---|---|---|---|
| 当日记录（草稿） | 每个「日期 + 作业内容 + 模式」一条，含逐人明细 | 自动保存；**草稿超过 90 条时只留最近 60 条 + 当前那条** | 敲键盘即自动存（300ms 防抖） |
| 历史记录 | 同一条记录的**完整逐人明细** + 汇总指标 | 最多 **200 条**，超出淘汰最早 | `Ctrl+S` / 💾【更新修改】手动固化；**切换日期 / 模式 / 作业内容时也会自动固化**（Toast「已保存上一条」） |
| 自动快照 | 全量状态 | IndexedDB 保留最近 **5 份** | 每 30 秒自动 |

按这个规则换算：

- **一周**：7~21 条，任何模式都远远够用。
- **一个月、每天只录一种模式**：30 条草稿，在 60~90 区间内，安全。
- **一个月、每天三种模式全录**：约 90 条，会触发草稿淘汰（只留最近 60 条 + 当前）；**已固化成历史的记录不受影响**，仍按 200 条保留。
- **容量**：50 人一条记录约 4.4 KB，`localStorage` 5 MB，理论上能放约 1000 条；历史 200 条约 0.9 MB。真正的限制是上面的条数策略，不是空间。

> 补充一句实话：草稿被淘汰后，那天的**逐人明细仍完整保存在历史记录里**（导出备份的 JSON 里有），只是网格不能再「切回那天继续改」。所以想保留可编辑状态，就别让草稿堆过 90 条。

**要跨月 / 跨学期留档，唯一可靠的办法是导出备份**：每月初（或月末）在【设置 → 📦 导出备份】存一个 JSON（建议命名 `学情登记-2026-10.json`），这是脱离浏览器、脱离这台电脑的档案；需要时【📥 导入备份】即可回到当时的状态。

**会丢数据的场景**：清浏览器数据 / 清除网站数据、无痕模式、换电脑、换浏览器（Edge ↔ Chrome 各自一份）、学校的还原卡策略。

## 6. 给开发者

### 环境要求

| 项 | 要求 | 说明 |
|---|---|---|
| Node | **≥ 22** | `package.json` 的 `engines` 已声明。Node 20 下 `vite-plugin-pwa@0.20` 的 ESM 产物执行 `require('workbox-build')` 会抛 `Dynamic require of "workbox-build" is not supported`，`vite build` 直接中断——这不是代码坏了。升级 `vite-plugin-pwa` 后才可放宽到 Node 20 |
| pnpm | 9.x | `corepack enable` 后 `corepack prepare pnpm@9.15.0 --activate` |
| 浏览器 | Chrome / Edge | E2E 走本机已装 Edge（`PW_CHANNEL=msedge`），不额外下载浏览器 |

```bash
pnpm install --frozen-lockfile
pnpm dev          # 本地开发
pnpm typecheck    # tsc --noEmit
pnpm lint         # 分层约束检查（domain/store/infra 不得反向依赖）
pnpm test:run     # 单测 + 组件测试（Vitest + jsdom）
pnpm test:e2e     # E2E（Playwright，默认走本机 Edge 通道）
pnpm build        # 构建 dist/，并把入口内联进 index.html（双击可用）
```

### 目录

```
src/
├─ domain/     # 纯函数层：类型、统计、名单、报表、海报模型、语音解析、折行、舍入
├─ store/      # zustand 分片：record / undo / class / settings / history / ui
├─ infra/      # 持久化、IndexedDB、剪贴板、语音、海报栅格化（唯一允许碰浏览器 API 的地方）
├─ hooks/      # 输入引擎、自动保存、语音、统计 / 报表 / 海报 selector 包装
├─ components/ # 四区布局 + 网格 + 弹窗 + 图表
└─ styles/     # 设计令牌 + 全局样式（Tailwind 关掉 preflight，只作原子类备用）
```

### 两条工程约定

1. **统计 / 名单 / 报表 / 海报模型必须是纯函数**，输入输出都是普通对象，能脱离 DOM 单测（`tests/unit` 里逐字比对 PRD 黄金样例 A/B/C）。
2. **运行时依赖只有 5 个**：`react` `react-dom` `zustand` `clsx` `html-to-image`。图表是手写 SVG，没有引图表库。

### 构建产物为什么要把 JS 内联进 index.html

设计要求「双击 `dist/index.html` 就能用」，但 Chrome / Edge 对 `file://` 下的 `<script type="module" src>` 和外部 CSS 会做 CORS 拦截，直接双击会白屏。因此 `pnpm build` 的最后一步（`scripts/inline-dist.mjs`）会把入口 JS 与 CSS 内联进 HTML——内联模块不发起跨源请求，双击即用；同时 `dist/assets/` 仍原样保留，供 http 托管与 PWA 预缓存使用。
