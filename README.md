# 学情登记分析系统 V4

> 为初中语文老师刘露定制的**作业 / 测验极速登记**工具：一节早读录完全班，一键出报表文案、单条海报与当日汇总长图。
>
> 纯前端、纯本地、**零网络请求**（唯一例外：老师自己点「语音」时才调用浏览器语音识别）。断网、飞行模式、关 Wi-Fi 都能照常用。

---

## 1. 怎么用（老师视角）

### 双击打开（最省事）

下载 ZIP 解压后，进 `dist/` 目录，**三选一**：

| 入口 | 效果 |
| --- | --- |
| **`启动学情登记系统.cmd`**（推荐 Windows） | 无边框窗口，像桌面应用：无地址栏、无标签页，任务栏显示樱花图标 |
| **`学情登记系统.html`** | 普通浏览器窗口打开（Edge / Chrome），不装东西、不联网、不用服务器 |
| `index.html` | 与上面**完全相同**的应用（兼容旧链接 / 静态服务器 / 测试，日常不用管） |

> 首次双击 `.cmd` 时 Windows 可能提示「打开文件 - 安全警告」（文件来自网络），点「打开」即可，只此一次。
> macOS 用户双击 `学情登记系统.html` 用 Chrome 打开后：菜单 ⋮ → 更多工具 → 创建快捷方式 → 勾选「在窗口中打开」，之后从程序坞启动即为无边框窗口。

> 数据存在**这台电脑的这个浏览器**里；换电脑请用【设置 → 导出备份】搬数据。

### 第一次打开要做的三件事

1. 【设置】⚙️ 填班级名、学校名、老师姓名（海报与报表署名用），确认学生人数（默认 50）。
2. 名单不是 1~50 号？点 📁 导入花名册（粘贴文本 / CSV / TXT 均可）。
3. 选登记类型、填日期与作业内容，开始敲键盘。

> 想先试一遍？仓库自带一份 40 人示例名单：`samples/花名册-40人.csv`（CSV，含表头，Excel 可直接打开）
> 或 `samples/花名册-40人.txt`（无表头，直接粘进导入框）。导入后人数会从 50 变成 40，少出的学号数据只隐藏、不删除。

## 2. V2 主要功能（8 条）

1. **评分方案**：每张登记表可选「等级 / 分数 / 过关 / 混合 / 纯文本」，同一张表里既能打 `A` 也能打 `96`。
2. **满分可配 + 百分比阈值**：满分 1–200，优秀/良好/及格按百分比（默认 90/80/60%），改完全局同步。
3. **四类登记 + 自定义**：听写默写、常规作业、质量监测（原「单元测试」）、自定义（可自填「作文」等名称）。
4. **请假 / 缺交 / 补交**：独立状态位，报表分【暂未提交】【已补交】【请假】三段，缺交可带补交说明。
5. **过关与「只看未过关」**：`G` 或 Enter 打勾，一键过滤只看没过的学生（保留原学号）。
6. **当日汇总长图**：一张图装下当天的听写、语文本、卷子，按录入顺序排列，超过 6 条自动截取。
7. **积分账本**：8 条可配置规则（连续 3 次全对 +5、缺交 −3、补交 −2…），幂等、可撤销、可看月度名次。
8. **多班级 + 月度/学期导出**：一个老师多个班数据完全隔离；导出 `.zip`（登记明细 / 月度积分 / 汇总三个 CSV，Excel 双击不乱码）。

此外还有：语音口令（十二号优秀、五号已更正、二十三号过关）、内置 19 章使用手册、v1 数据无损自动迁移。

## 2.5 V3 新增（体验与数据安全加固，v2.2.0）

根据 15 条真实课堂反馈（[`docs/05-需求说明书-V3.md`](docs/05-需求说明书-V3.md) / [`docs/06-设计说明书-V3.md`](docs/06-设计说明书-V3.md)）加固，评审先看[自测报告](docs/07-自测报告-v2.2.0.md)：

1. **数据安全优先**：数据格式升级到 v3（`xq.state.v3`），迁移前自动备份原文；主存写坏自动从 IndexedDB 快照恢复，坏数据另存 `xq.corrupt.*` 不丢弃；「内存空 + 磁盘有数」时阻止覆盖并给导出入口；【设置 → 数据】新增健康面板（主存/快照/坏块计数 + 导出/导入/回退/复制诊断）。
2. **换打开方式不丢数据**：记录「打开方式指纹」，换域名 / 换宿舍电脑打开时提示数据在各自空间，并提供导入恢复入口。
3. **过关只有一个入口**：所有统计、名单、汇总图、积分、筛选都走 `isPassed()`；过关规则可在设置里改（按白名单 / 按分数及格线 / 两者取并），听写「全对=过关」可开关。
4. **颜色两套色系**：等级格子七档色（A+ 到 D，边框实线→虚线→点线递进），分数格子四档百分比色，互不串用；三态（缺交 / 请假 / 补交）颜色之外再加角标与辅助文字，色弱也能分辨。
5. **动态键位与说明**：数字键按「本表启用的等级」从左到右绑定，说明行永远和实际键位一致（废除写死的旧提示）。
6. **分数录入防呆**：非法值（−5、超满分、满分未设）提交时整条拒绝 + 红框提示，绝不夹取半个脏值；听写 `12` = 错 12 个（900ms 两位数窗口）。
7. **补交门禁**：只有缺交与请假能补交，已录值 / 空白直接拒绝；候选名单自动过滤。
8. **海报升级**：当日 / 单条 / 本周三向切换；单条可换表立即重出；评价语（≤60 字）与可选学校署名；本周汇总按天拼接、空日写「当日无登记」、过长自动分卷。
9. **自定义积分规则**：条件闭集点选（不写代码），删除规则自动冲正已发积分。
10. **品牌与自适应**：标签页标题「刘露老师的学情登记本」+ 独立图标（file:// 双击也显示）；1280 / 1366 / 1920 三档密度。

> 老数据不用动：v1 / v2 / v3 打开自动升级，原始数据先备份再写（详见 [`docs/07-自测报告-v2.2.0.md`](docs/07-自测报告-v2.2.0.md) 的回滚一节）。

## 2.6 V4 新增（数字键消歧 + 布局重排 + 主题 + 手机端，v2.3.0 → v2.3.1）

根据 6 条真实课堂反馈与手机端调研（[`docs/08-需求说明书-V4.md`](docs/08-需求说明书-V4.md) / [`docs/09-设计说明书-V4.md`](docs/09-设计说明书-V4.md)）实现，评审先看[自测报告](docs/10-自测报告-v2.3.0.md)（v2.3.1 修复见 [`docs/11-自测报告-v2.3.1.md`](docs/11-自测报告-v2.3.1.md)）：

1. **数字键不再有歧义**：混合表（等级+分数）默认「数字＝等级」，提示条左侧的语义 chip 或反引号 `` ` `` 一键切到「数字＝分数」；切错语义时按无效键会有 Toast 说明，不静默吞键。
2. **四角分区单元格**：学号（左上）/ 印章（右上）/ 角标（右下）/ 主值（中部）各就各位，盖章 + 分数 + 缺交同时存在也不重叠。
3. **三段式布局**：输出带（报表/海报/汇总，4 键固定顺序）与录入带分开；1366×768 一屏全放下，高度有硬闸门（E2E 量 `scrollHeight ≤ 768`）。
4. **六套背景主题**：【设置 → 外观】粉 / 薄荷 / 天蓝 / 暖沙 / 夜间 / 素白，记住选择；素白是白底 + 中性灰按钮（不再沿用粉色主色）；夜间主题下页面文字自动切浅色（对比度 ≥4.5:1）；海报默认不跟随（白底、标题深色，发群更清楚），可手动开。
5. **手机端可用**：5 列网格、底部固定操作条（图标 4 项，**fixed 贴底不随滚动消失**，滚到任何学生都在眼前）、点格子底部升起数字键盘（等级行按方案档数全出，7 档也有 D）；键盘弹起时操作条让位；优先系统分享，不支持则下载。
6. **移动数据安全**：「添加到主屏幕」安装提示（可关闭）；每 7 天未导出提醒备份一次（iOS 会清理站点存储）。

### v2.3.1 修订（评审 + 4 条用户反馈）

- **手机端底部操作条真正 fixed**：v2.3.0 的 `sticky` 对文档流上半部元素无效，滚出屏幕就没了（E2E 旧断言只数 DOM 个数，属于假绿）——改为 `fixed` 贴视口底，断言改用 `boundingBox` 比对视口坐标。
- **夜间主题页面文字**：品牌名 / 参数标签 / 提示条改用浅色（实测对比度 1.20:1 → ≥10:1），规格补 FR-48.6-b。
- **等级表情可按等级配**：每个等级都能选「不显示」——只奖励想奖励的档位（如只给 A/A+ 配表情）。
- **海报大标题改深色**（原跟随品牌粉）、**评价语加深加粗**与页脚学校名区分。
- **纯白主题中性化**：主色从粉色改为石墨灰，素白名副其实。
- 手机端班级名完整显示（人数窄屏省略，不再裁字）；键盘等级行 7 档全出。

## 2.8 v2.5.6 – v2.6.3 新增（用户反馈与专项审查）

- **多表管理与键位**：登记等级补全 **B-**（八档 1..8）；同一天同模板的多张表在**主界面**就能直接切换，不再只能进海报预览里翻；汇总长图按表分节，每张表各写各的评价语。
- **看得更清楚**：等级旁的表情改到等级文字**下方独立一行**，三种版式（主网格 / 海报 / 汇总）分别给字号，不再互相遮挡；提示条把「哪个数字键对应哪个等级」做成色块，配色与该等级格子一致。
- **界面随屏幕走**：解除 1440px 内容上限，1600 / 1920 / 2560 三档逐级放大格子与字号。
- **过关规则说清了**：混合判定下等级值达到本表及格线时同样算过关（百分或等级取并集，规格原文）；设置页写明并列出当前勾选。
- **及格% 有下限了**：低于 5% 会被拒绝入库并提示，避免及格线过低导致几乎人人过关。
- **B- 两处遗漏补上**：`GRADE_LETTERS` 与 `GRADE_ORDER` 对齐；手机键盘等级行允许换行、每键可缩，375px 屏 8 档见得到也点得到。
- **过关规则跟着方案走**：等级制只看本表等级白名单，分数制可选「及格 / 良好 / 优秀」档位，混合制两套并存；规则搬进「本表设置」，不再和系统设置分家。
- **改方案先问再清**：改方案类型或满分时，先提示会清空多少格，确认后清空（可撤销），取消则整体回滚。
- **新建登记才建表**：作业内容只是待新建的名称，点「＋ 新建登记」才多一张表，同天黑板上不再冒出删不完的空表。
- **界面信息补齐**：顶栏显示当前时间与学期，页脚显示版本号，默认背景改为纯白。
- **未启用等级有入口**：提示条多一个「未启用…，点此添加」，一步到本表设置。
- **登记表可以删了**：「选择登记表」只列真正录过的表，随手打字的空表不再变成永久选项；参数行新增「删除此表」（二次确认），删掉后从选择器、当日汇总、历史里一起消失。
- **缺交 / 请假可选是否算过关**：设置页新增两个开关（默认关闭，保持原有行为）。
- **数据安全**：导入花名册换名单必确认可回退；保存失败可见化；多窗口写盘比对磁盘指纹，不静默覆盖；「录一整天不切表就关浏览器」不再丢数据。

## 3. 快捷键

| 键 | 作用 |
|---|---|
| `1`–`9` `0` `.` | 输入分数（`.` 仅一次，最多 1 位小数）；混合表按当前语义执行，见下 |
| `` ` ``（反引号） | 混合表切换数字键语义：等级 ⇄ 分数 |
| `A` `B` `C` `D` | 打等级，随后 `+` / `-` 修饰（`A` → `A-`） |
| `Enter` | 提交分数并前进；过关制下 = 打过关 |
| `G` / `X` / `L` | 过关 / 缺交 / 请假（再按一次取消） |
| `M` | 补交（填说明） |
| `F2` / 双击 | 自定义文字 |
| `空格` | 盖章（已更正 / 优秀） |
| `Tab` | 跳到下一个还没处理的学生 |
| `/` | 搜学号并跳转 |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做 |
| `Ctrl+S` | 保存到历史（固化） |
| `Ctrl+Enter` / `Ctrl+J` | 生成报表 / 单条海报 |
| `Ctrl+M` | 语音开关 |

## 4. 数据与隐私

- 全部数据存在浏览器 `localStorage`（当前 `xq.state.v4`），每 30 秒在 IndexedDB 留一份快照（保留 5 份），刷新 / 强关不丢；主存损坏自动从快照自愈，坏原文另存 `xq.corrupt.*`。
- 页面不发任何网络请求；语音识别只在**你主动点击语音按钮**后才调用浏览器自带能力（Chrome 的中文识别依赖网络服务，Edge 通常更稳）。
- 【设置 → 数据】可导出/导入全量 JSON 备份（导入前自动留底，可一键回退）；「内存空 + 磁盘有数」时阻止覆盖（INV-24）。
- **数据迁移**：v1 / v2 / v3 首次打开自动升级到 v4，原始 JSON 备份在 `xq.backup.v1` / `xq.backup.v2` / `xq.backup.v3`；升级失败进入只读模式并提供【下载原始备份】，绝不覆盖老数据。
- 手机端建议「添加到主屏幕」当 App 用；系统每 7 天未导出会提醒备份——iPhone 久不用会清理网页数据，这是纯网页版唯一的真实风险。

## 5. 给开发者

### 环境要求

| 项 | 要求 | 说明 |
|---|---|---|
| Node | **≥ 22** | `package.json` 的 `engines` 已声明。Node 20 下 `vite-plugin-pwa@0.20` 会抛 `Dynamic require of "workbox-build" is not supported`（不是代码问题） |
| pnpm | 9.x | `corepack enable && corepack prepare pnpm@9.15.0 --activate` |
| 浏览器 | Chrome / Edge | E2E 走本机 Edge（`PW_CHANNEL=msedge`），不下载浏览器 |

```bash
pnpm install --frozen-lockfile
pnpm dev          # 开发
pnpm typecheck    # tsc --noEmit
pnpm lint         # 分层约束检查（domain/store/infra 不得反向依赖）
pnpm test:run     # 单测 + 组件测试（Vitest）
pnpm test:e2e     # E2E（Playwright，56 条：V1/V2/V3 回归 42 + V4 9 + v2.3.1 1 + v2.4.0 2 + v2.5.0 3）
pnpm build        # 构建 dist/：入口内联 + 改名「学情登记系统.html」+ 生成 cmd 启动器（双击可用）
```

### 目录

```
src/
├─ domain/      # 纯函数：types/scoring/grading/stats/roster/report/points/exporter/summary/poster/posterWeek/passRule/tone/keymap/hint/scoreInput/makeup/migrate/manual/voice/digitKey/theme/remind/*
├─ store/       # zustand 分片：class / sheet / entry / point / ui / undo
├─ infra/       # 持久化、存储健康、备份、IDB、剪贴板、下载、ZIP、栅格化、语音识别封装
├─ hooks/       # 输入引擎、自动保存、语音
├─ components/  # 布局四区 + 网格 + 弹窗 + 图表 + 海报（当日/单条/本周）
└─ styles/      # 设计令牌（七档等级色/四档分数色/三态角标/三档密度）+ 全局样式
```

### 三条工程约定

1. **纯函数先行**：统计 / 名单 / 报表 / 导出 / 积分 / 语音解析全部在 `domain/`，可脱离 DOM 单测（黄金样例 A/B/C 逐位断言）。
2. **零新增运行时依赖**：只用 react / react-dom / zustand / clsx / html-to-image。ZIP、拼音近似表、手册都是手写实现。
3. **`dist/assets` 保留 + 入口内联 + 入口改名**：满足「双击就用」（`file://` 下外部 module 会被 CORS 拦截）；`postbuild-app.mjs` 把入口改名为「学情登记系统.html」、`index.html` 留同内容镜像、并生成 Windows `--app` 无边框启动器（`scripts/postbuild-app.mjs` 头部注释记录了为什么不能用 0 秒跳转页）。
