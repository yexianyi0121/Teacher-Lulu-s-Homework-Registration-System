# 学情登记管理系统

面向中小学教师的**课堂作业 / 测验极速登记**工具：一节早读录完全班，一键生成报表文案、单条海报、当日与本周汇总长图。

- 纯前端、纯本地运行，数据只保存在本机浏览器，不上传服务器
- 支持等级、分数、过关、混合、听写文本五种登记方式
- 支持积分规则、花名册导入、语音录入、搜索定位
- 断网可用，Windows 双击即开

当前版本：**v2.8.2**

---

## 快速开始

1. 下载并解压本项目。
2. 进入 `dist` 目录：
   - 双击 **`启动学情登记系统.cmd`**（Windows 推荐，无边框窗口打开）
   - 或直接用 Edge / Chrome 打开 **`学情登记系统.html`**
3. 首次使用：右上角 ⚙️ 设置班级信息 → 导入花名册（可选）→ 选择登记类型 → 点「＋ 新建登记」在弹窗里填写作业内容 → 开始录入。

> 首次运行 `.cmd` 若出现安全提示，点「打开」即可。

## 主要功能

- **五种登记类型**：常规作业（等级）、听写默写（错几/全对）、质量监测（分数）、混合制、纯文本。
- **极速键盘录入**：数字键录入，G 过关、X 缺交、L 请假、空格盖章；支持秒跳与批量操作。
- **每表独立方案**：满分、优秀/良好/及格阈值、过关等级，都可按表单独设置。
- **先建表再登记**：新建登记弹窗填写作业内容；表名可随时修改（保留已录数据、重名会被拒绝）。
- **空态引导**：当天该类型还没有表时只显示一个大大的「＋ 新建登记」按钮，避免误录。
- **日期月历**：有登记的日期高亮标记，悬浮显示当天已登记的表名；每天自动落在今天的空表。
- **搜索学号**：命中学生强高亮、其余格子变暗，回车直达。
- **一键输出**：文字报表、单条海报、当日汇总长图、本周汇总长图。
- **积分**：自动规则（如连续三次全对加分）、排行榜、手动加减分。
- **数据安全**：本地自动保存、导出/合并导入备份、定期备份提醒。

## 数据与备份

- 数据保存在**当前电脑的当前浏览器**中，不会上传。
- 换电脑或清理浏览器数据前，请先到「设置 → 数据 → 📦 导出全部数据」导出 JSON 备份。
- 新设备用「📥 导入恢复」导入，**合并**方式，不会覆盖已有登记。
- 可在设置里配置「每 7 天 / 30 天提醒一次」的备份提醒。

## 更新

打开「设置 → 关于 → ⬆️ 一键更新」即可前往 GitHub Releases 下载最新版本。
替换文件后照常启动即可；更新不会影响浏览器里的数据（仍建议先导出备份）。

## 数据安全

- 每次启动前自动备份浏览器数据（最近 20 次，位于 `%LOCALAPPDATA%\XueQingBackup`）。
- 如果打开后看不到数据：双击 `dist/恢复与排查.cmd` → 扫描并打开“数据所在配置”，或从自动备份恢复。详见使用手册。
