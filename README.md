# 学情登记分析系统 V3

> 为初中语文老师刘露定制的**作业 / 测验极速登记**工具：一节早读录完全班，一键出报表文案、单条海报与当日汇总长图。
>
> 纯前端、纯本地、**零网络请求**（唯一例外：老师自己点「语音」时才调用浏览器语音识别）。断网、飞行模式、关 Wi-Fi 都能照常用。

---

## 1. 怎么用（老师视角）

### 双击打开（最省事）

直接双击仓库里的 **`dist/index.html`**，用 Chrome / Edge 打开即可：不装东西、不联网、不用服务器。

> 数据存在**这台电脑的这个浏览器**里；换电脑请用【设置 → 导出备份】搬数据。

### 第一次打开要做的三件事

1. 【设置】⚙️ 填班级名、学校名、老师姓名（海报与报表署名用），确认学生人数（默认 50）。
2. 名单不是 1~50 号？点 📁 导入花名册（粘贴文本 / CSV / TXT 均可）。
3. 选登记类型、填日期与作业内容，开始敲键盘。

> 想先试一遍？仓库自带一份 40 人示例名单：`samples/花名册-40人.csv`（CSV，含表头，Excel 可直接打开）
> 或 `samples/花名册-40人.txt`（无表头，直接粘进导入框）。导入后人数会从 50 变成 40，少出的学号数据只隐藏、不删除。

## 2. V2 主要功能（8 条）

1. **评分方案**：每张登记表可选「等级 / 分数 / 过关 / 混合 / 纯文本」，同一张表里既能打 `A` 也能打 `96`。
2. **满分可配 + 百分比阈值**：满分 1–200，优秀/良好/及格按百分比（默认 90/80/60%），改完全局同步。
3. **四类登记 + 自定义**：听写默写、常规作业、质量监测（原「单元测试」）、自定义（可自填「作文」等名称）。
4. **请假 / 缺交 / 补交**：独立状态位，报表分【暂未提交】【已补交】【请假】三段，缺交可带补交说明。
5. **过关与「只看未过关」**：`G` 或 Enter 打勾，一键过滤只看没过的学生（保留原学号）。
6. **当日汇总长图**：一张图装下当天的听写、语文本、卷子，按录入顺序排列，超过 6 条自动截取。
7. **积分账本**：8 条可配置规则（连续 3 次全对 +5、缺交 −3、补交 −2…），幂等、可撤销、可看月度名次。
8. **多班级 + 月度/学期导出**：一个老师多个班数据完全隔离；导出 `.zip`（登记明细 / 月度积分 / 汇总三个 CSV，Excel 双击不乱码）。

此外还有：语音口令（十二号优秀、五号已更正、二十三号过关）、内置 12 章使用手册、v1 数据无损自动迁移。

## 2.5 V3 新增（体验与数据安全加固，v2.2.0）

根据 15 条真实课堂反馈（[`docs/05-需求说明书-V3.md`](docs/05-需求说明书-V3.md) / [`docs/06-设计说明书-V3.md`](docs/06-设计说明书-V3.md)）加固，评审先看[自测报告](docs/07-自测报告-v2.2.0.md)：

1. **数据安全优先**：数据格式升级到 v3（`xq.state.v3`），迁移前自动备份原文；主存写坏自动从 IndexedDB 快照恢复，坏数据另存 `xq.corrupt.*` 不丢弃；「内存空 + 磁盘有数」时阻止覆盖并给导出入口；【设置 → 数据】新增健康面板（主存/快照/坏块计数 + 导出/导入/回退/复制诊断）。
2. **换打开方式不丢数据**：记录「打开方式指纹」，换域名 / 换宿舍电脑打开时提示数据在各自空间，并提供导入恢复入口。
3. **过关只有一个入口**：所有统计、名单、汇总图、积分、筛选都走 `isPassed()`；过关规则可在设置里改（按白名单 / 按分数及格线 / 两者取并），听写「全对=过关」可开关。
4. **颜色两套色系**：等级格子七档色（A+ 到 D，边框实线→虚线→点线递进），分数格子四档百分比色，互不串用；三态（缺交 / 请假 / 补交）颜色之外再加角标与辅助文字，色弱也能分辨。
5. **动态键位与说明**：数字键按「本表启用的等级」从左到右绑定，说明行永远和实际键位一致（废除写死的旧提示）。
6. **分数录入防呆**：非法值（−5、超满分、满分未设）提交时整条拒绝 + 红框提示，绝不夹取半个脏值；听写 `12` = 错 12 个（900ms 两位数窗口）。
7. **补交门禁**：只有缺交与请假能补交，已录值 / 空白直接拒绝；候选名单自动过滤。
8. **海报升级**：当日 / 单条 / 本周三向切换；单条可换表立即重出；评价语（≤60 字）与可选学校署名；本周汇总按天拼接、空日写「当日无登记」、过长自动分卷。
9. **自定义积分规则**：条件闭集点选（不写代码），删除规则自动冲正已发积分。
10. **品牌与自适应**：标签页标题「刘露老师的学情登记本」+ 独立图标（file:// 双击也显示）；1280 / 1366 / 1920 三档密度。

> 老数据不用动：v1 / v2 打开自动升级，原始数据先备份再写（详见 [`docs/07-自测报告-v2.2.0.md`](docs/07-自测报告-v2.2.0.md) 的回滚一节）。

## 3. 快捷键

| 键 | 作用 |
|---|---|
| `1`–`9` `0` `.` | 输入分数（`.` 仅一次，最多 1 位小数） |
| `A` `B` `C` `D` | 打等级，随后 `+` / `-` 修饰（`A` → `A-`） |
| `Enter` | 提交分数并前进；过关制下 = 打过关 |
| `G` / `X` / `L` | 过关 / 缺交 / 请假（再按一次取消） |
| `M` | 补交（填说明） |
| `F2` / 双击 | 自定义文字 |
| `空格` | 盖章（已更正 / 优秀） |
| `Tab` | 跳到下一个还没处理的学生 |
| `/` | 搜学号并跳转 |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做 |
| `Ctrl+S` | 保存到历史（固化） |
| `Ctrl+Enter` / `Ctrl+J` | 生成报表 / 单条海报 |
| `Ctrl+M` | 语音开关 |

## 4. 数据与隐私

- 全部数据存在浏览器 `localStorage`（当前 `xq.state.v3`），每 30 秒在 IndexedDB 留一份快照（保留 5 份），刷新 / 强关不丢；主存损坏自动从快照自愈，坏原文另存 `xq.corrupt.*`。
- 页面不发任何网络请求；语音识别只在**你主动点击语音按钮**后才调用浏览器自带能力（Chrome 的中文识别依赖网络服务，Edge 通常更稳）。
- 【设置 → 数据】可导出/导入全量 JSON 备份（导入前自动留底，可一键回退）；「内存空 + 磁盘有数」时阻止覆盖（INV-24）。
- **数据迁移**：v1 / v2 首次打开自动升级到 v3，原始 JSON 备份在 `xq.backup.v1` / `xq.backup.v2`；升级失败进入只读模式并提供【下载原始备份】，绝不覆盖老数据。

## 5. 给开发者

### 环境要求

| 项 | 要求 | 说明 |
|---|---|---|
| Node | **≥ 22** | `package.json` 的 `engines` 已声明。Node 20 下 `vite-plugin-pwa@0.20` 会抛 `Dynamic require of "workbox-build" is not supported`（不是代码问题） |
| pnpm | 9.x | `corepack enable && corepack prepare pnpm@9.15.0 --activate` |
| 浏览器 | Chrome / Edge | E2E 走本机 Edge（`PW_CHANNEL=msedge`），不下载浏览器 |

```bash
pnpm install --frozen-lockfile
pnpm dev          # 开发
pnpm typecheck    # tsc --noEmit
pnpm lint         # 分层约束检查（domain/store/infra 不得反向依赖）
pnpm test:run     # 单测 + 组件测试（Vitest）
pnpm test:e2e     # E2E（Playwright，36 条：V1/V2 回归 25 + V3 数据安全与体验 11）
pnpm build        # 构建 dist/ 并把入口内联进 index.html（双击可用）
```

### 目录

```
src/
├─ domain/      # 纯函数：types/scoring/grading/stats/roster/report/points/exporter/summary/poster/posterWeek/passRule/tone/keymap/hint/scoreInput/makeup/migrate/manual/voice/*
├─ store/       # zustand 分片：class / sheet / entry / point / ui / undo
├─ infra/       # 持久化、存储健康、备份、IDB、剪贴板、下载、ZIP、栅格化、语音识别封装
├─ hooks/       # 输入引擎、自动保存、语音
├─ components/  # 布局四区 + 网格 + 弹窗 + 图表 + 海报（当日/单条/本周）
└─ styles/      # 设计令牌（七档等级色/四档分数色/三态角标/三档密度）+ 全局样式
```

### 三条工程约定

1. **纯函数先行**：统计 / 名单 / 报表 / 导出 / 积分 / 语音解析全部在 `domain/`，可脱离 DOM 单测（黄金样例 A/B/C 逐位断言）。
2. **零新增运行时依赖**：只用 react / react-dom / zustand / clsx / html-to-image。ZIP、拼音近似表、手册都是手写实现。
3. **`dist/assets` 保留 + 入口内联**：满足「双击 index.html 可用」（`file://` 下外部 module 会被 CORS 拦截）。
